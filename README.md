# SQL Sales Trend Analysis

## Project Overview

This project analyzes an online sales dataset using SQL aggregation techniques to uncover monthly sales trends, revenue patterns, product performance, and regional insights. The analysis demonstrates the use of SQL functions such as SUM(), COUNT(), GROUP BY, ORDER BY, and LIMIT to generate meaningful business insights.

---

## Objectives

- Analyze monthly revenue trends
- Measure monthly order volume
- Identify top-performing months
- Evaluate product category performance
- Analyze regional sales distribution
- Discover best-selling products
- Examine payment method usage

## Analysis Performed

### 1. Monthly Revenue Analysis
Calculated total revenue generated each month.

### 2. Monthly Order Volume Analysis
Calculated monthly order counts using distinct transaction IDs.

### 3. Monthly Sales Trend Analysis
Combined revenue and order volume to identify sales patterns.

### 4. Top 3 Months by Revenue
Identified the highest-performing months.

### 5. Revenue by Product Category
Analyzed category-wise revenue contribution.

### 6. Revenue by Region
Compared revenue across regions.

### 7. Top Selling Products
Identified products with the highest units sold.

### 8. Revenue by Payment Method
Analyzed customer payment preferences.

### 9. Average Order Value
Calculated average revenue generated per transaction.
